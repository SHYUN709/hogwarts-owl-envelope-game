# 호그와트 부엉이 편지

학교 행사(홍보대사의 밤)용 기숙사 대항 봉투 게임. `index.html`을 크롬/엣지로 열면 바로 실행되고, 인터넷 없이도 동작합니다.
진행 방법은 [사용법.md](사용법.md), 문제는 `content.js`, 점수·규칙 숫자는 `config.js`.

## 사용한 오픈소스 (모두 `vendor/` 폴더에 포함)

| 자료 | 만든 사람 | 라이선스 |
|---|---|---|

| 아이콘: magic-potion | Delapouite | CC BY 3.0 |
| 아이콘: badger | Caro Asercion | CC BY 3.0 |

| canvas-confetti 1.9.3 | Kiril Vatev | ISC (`vendor/LICENSE-canvas-confetti.txt`) |

아이콘 출처: [game-icons.net](https://game-icons.net). 원본 SVG는 `vendor/icons/`에 있고, 게임은 거기서 모양만 뽑은 `vendor/icons.js`를 씁니다. 색(금색 그라데이션)은 게임에서 입힌 것입니다.
